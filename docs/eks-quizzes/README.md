# EKS 학습 퀴즈 기록

이 디렉토리는 **EKS 학습 마일스톤마다 "구축 후 이해도 퀴즈"의 결과**를 보관한다.

## 왜 존재하나

EKS 트랙의 목적은 결과물이 아니라 **인프라 이해**다. 그런데 실시간 개념 설명은
실행 momentum에 밀려 누락되기 쉽다(실제로 Task 8에서 발생). 그래서 이해 검증의
**강제 체크포인트를 "구축 후 퀴즈"로 옮기고, 기계가 막게** 했다 — QA 루프(`assert-qa-run.sh`)와
같은 철학이다.

## 어떻게 동작하나

1. 학습 마일스톤은 브랜치를 **`stage/eks-*`** 로 만든다 (예: `stage/eks-1-ecr`).
2. 구축·검증(apply 왕복 등)이 끝나면 **PR 생성 전에** `skills/universal/quiz.md`의
   "EKS 학습 마일스톤 모드"로 퀴즈를 본다. 재료는 `docs/eks-migration-log.md`의 그 세션 실측.
3. 결과를 `docs/eks-quizzes/<브랜치를 -로>.md`에 기록한다
   (`stage/eks-1-ecr` → `stage-eks-1-ecr.md`).
4. 전 문제 풀이 + 틀린 문제 재검토까지 끝나면 파일 맨 아래에 정확히 `<!-- QUIZ-PASSED -->`.
5. **`assert-eks-quiz.sh` 훅**이 `gh pr create` 시 이 파일·마커가 없으면 PR을 차단한다.

## 파일 형식

```
# EKS 학습 퀴즈 — <마일스톤명>
- 브랜치: stage/eks-1-ecr   · 날짜: YYYY-MM-DD   · HEAD: <sha>

## Q1. <질문 — 무엇을/왜/트레이드오프 또는 개념>
- 사용자 답: <답>
- 정오: ✅/❌   - 근거: <파일:라인 / 로그 엔트리 / 리소스>

## 요약
- 맞음 N / 틀림 M. 틀린 문제 재검토: <항목 또는 "없음">

<!-- QUIZ-PASSED -->
```

> ⚠️ 미완인 채 `<!-- QUIZ-PASSED -->` 마커만 먼저 넣지 말 것 — 그건 학습을 우회하는 것이다.
