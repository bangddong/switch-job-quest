### 그리고 이 돈은 학습 트랙과 **배타**다

`infra/aws-eks/README.md` 「확정 전략」이 잡아둔 학습 예산은 **주 25h × 26주 = 650h, $110~163** 이다.
잔여가 $194 이므로 **둘 다는 못 한다.**

```
학습 트랙 완주  $110~163   →  남는 것 $31~84  =  0.7~2.0주  (3주도 안 된다)
3주 데모        $126       →  남는 것 $68     =  학습 272h  (계획의 42%)
```

⚠️ **이 트레이드오프를 적어둔 문서가 레포에 0건이었다.** 「확정 전략」의 `잔액 활용` 불릿은
*"남는 크레딧으로 3~6주 데모"* 라고만 썼고, **같은 블록이 그 위 네 줄에서 650h 를 이미 배정**해뒀다.
***조항이 자기 산술과 충돌한다.***

## 🔴 계획이 성립하지 않는 것 3건

D-013 이 22건 Blindspot 중 6건을 이 등급으로 분류했던 것과 같은 자리다.
아래 3건은 **기간 한정 전제에서 새로 생겼거나 성질이 바뀐 것**이다.

### T-1. 복귀 경로가 **코드로 봉쇄**돼 있다 — 편도엔 없던 문제

```
infra/aws-eks/scripts/db-backup.sh   설계 근거 ⑥
  "prod Neon 에 붙을 수 없다 — 구조적으로.
   이 스크립트는 오직 kubectl exec 로 클러스터 안 파드에 명령할 뿐 DB 호스트를 인자로 받지 않는다"
infra/aws-eks/scripts/db-restore.sh  POD="${POD:-postgres-0}" · 모든 접근이 kubectl exec
```
<!-- verify: infra/aws-eks/scripts/db-backup.sh -->
<!-- verify: infra/aws-eks/scripts/db-restore.sh -->

백업·복구 짝은 **in-cluster → S3 → 같은 in-cluster** 왕복만 지원한다.
**EKS → Neon 방향의 코드·절차·문서는 0건이다.**

🔴 **복귀 경로를 만든다는 것은 그 스크립트가 *자랑으로 적어둔* 설계 근거를 제거하는 것이다.**
*"제약이 옵션이 아니라 불가능으로 구현돼 있다"* 가 그 파일의 자기 서술인데, 왕복은 그걸 옵션으로 되돌린다.

- `pg_dumpall` 금지(설계 근거 ④)는 **장애물이 아니다** — 단일 DB `pg_dump -Fc` 로 충분하고 복귀에도 쓰인다.
- 🔑 **센티넬(설계 근거 ⑦)의 판정 논리가 prod 에서 뒤집힌다.** 센티넬이 필요했던 이유는
  *"Flyway 재시드가 같은 결과를 낸다"* 였는데 **prod 사용자 데이터는 Flyway 가 재생성할 수 없다.**
  `0-bootstrap/s3-backups.tf` 가 이미 *"prod 이관 시 이 판단은 뒤집힌다"* 라고 써뒀다.

**선택지**

| | 내용 | 대가 |
|---|---|---|
| **ⓐ 창 동안 Neon 을 계속 쓴다** | in-cluster Postgres 를 안 띄운다 | 복귀 문제 **소멸**. 단 ESO 경로 신설 필요(아래) + *"EKS 안에 DB 가 있다"* 는 데모 가치 상실 |
| ⓑ in-cluster + 복귀 도구 신설 | `db-backup.sh` 에 호스트 인자 추가 | 설계 근거 ⑥ 제거 · 왕복 리허설 필수 · 실패 시 **3~6주치 prod 데이터 소실** |
| ⓒ in-cluster + 복귀 포기 | 창 동안 데이터를 버린다 | **prod 에서 불가** |

> ⚠️ **ⓐ 도 공짜가 아니다.** `k8s/eso/` 의 두 ExternalSecret 은 **같은 이름의 Secret(`core-api-db`)을
> 배타적으로** 만들고 **어느 쪽에도 Neon 호스트가 들어갈 자리가 없다.** 세 번째 ExternalSecret +
> Secrets Manager 항목 + Neon 재발급이 필요하다.
> <!-- verify: k8s/eso/externalsecret-db.yaml -->

학습 세션은 수 시간이라 턴이 계속 있었다. **3~6주 연속 가동은 "수 주 연속 무턴"이 기본값**이다.
⇒ 2h stale 판정을 **거의 확실히** 통과 ⇒ **prod destroy.**

🔴 **그리고 "리퍼를 끄면 된다"가 아니다.**

```
eks-session-marker.sh:48   cluster_dir=$ROOT/infra/aws-eks/2-cluster    ← 리터럴 1개
eks-reaper.sh:151          CLUSTER_DIR=$(grep '^cluster_dir=' "$MARKER" …)
2-cluster/backend.tf       key = "2-cluster/terraform.tfstate"          ← 리터럴, 보간 불가
```
마커는 **파일 하나**, destroy 대상은 **디렉토리 하나**다. 끄면 **학습 세션의 dead man's switch 도 같이 꺼진다.**
둘을 가르려면 2클러스터가 필요한데 state key 가 리터럴이라 **현재 IaC 로 불가능**하다.

⇒ **T-3 이 이 계획의 1순위 하드 블로커다.** D-013 은 B-1 을 *"영구 이관이면 재설계"* 로 미뤘는데,
**기간 한정에서도 축소되지 않는다.** `EKS_REAPER_TTL` 을 창 길이로 늘리는 저비용 우회조차
**plist 에 환경변수 키가 없어** plist 수정 + 리퍼 재설치를 강제한다.

## 항목 7 이 이 계획의 **본체**가 된다

D-013 이 항목 7(안전장치 개정)을 이관 후로 민 사유는 *"B-1·B-18 이 **이관 후 토폴로지에 의존**하는데
그 결정이 레포에 없다"* 였다. **기간 한정은 토폴로지를 1클러스터로 확정한다** → **그 사유가 소멸한다.**

### 13건 재판정 — 줄지 않았다

D-013 「항목 7 — 착수 설계」⑥ 표 13건을 기간 한정 전제로 다시 판정했다.

| 판정 | 수 | 항목 |
|---|:-:|---|
| 🟢 소멸 | **4** | U-T(ACM 갱신) · U-Q(`guard-local-layers`) · U-N(리퍼 필터) · U-O(탐지 범위) |
| 🟡 축소 | **1** | U-U(실패 6종) |
| ⬜ 그대로 | **5** | U-R(예산 20단계) · U-M(마커 자가치유) · U-I · U-J · U-W |
| 🔴 **오히려 커짐** | **3** | **U-L**(하트비트) · **U-P**(plist TTL) · **U-V**(JWT 왕복) |

***영구 운영 전용 항목이 대폭 줄 것이라는 예상은 틀렸다. 4건만 줄고 3건은 커졌다.***

**소멸 근거 (대표)**
- **U-T** — ACM 만료 **2027-04-02** > 크레딧·플랜 만료 **2027-01-15**. 자동 갱신 시도(통상 만료 60일 전
  ≈2027-02-01)도 플랜 만료 이후다. 창이 언제 열려도 갱신 창에 안 들어온다.
  ⚠️ **U-T 를 지우면서 ACM 을 통째로 빼면 틀린다** — 아래 「왕복이 만드는 것」의 도메인 검증이 남는다.
- **U-Q** — `infra-ci.yml` 의 guard 는 `2-cluster` 가 **apply 매트릭스**에 들어갈 때만 fail 한다.
  기간 한정도 `2-cluster` 는 로컬 apply/destroy 이므로 매트릭스를 건드릴 이유가 없다.
- **U-N**(리퍼의 EKS 이름 필터 비대칭) — 필터는 *"내 클러스터만 죽여라"* 를 위한 것인데
  **계정에 클러스터가 1개면 구분할 대상이 없다.** D-013 이 이미 *"클러스터가 1개면 리퍼를 **지워야** 하고,
  2개면 IaC 가 먼저다 — **어느 쪽에서도 필터는 해법이 아니다**"* 로 자기 판단을 철회해뒀다.
  ⚠️ **필터가 불필요해질 뿐 리퍼 문제 자체는 T-3 로 남는다.** U-N 소멸을 B-1 해소로 읽지 말 것.
- **U-O**(탐지 범위 ≠ 조치 범위) — **2클러스터 전제 항목**이다. 기간 한정은 토폴로지를
  1클러스터로 확정하므로(결정 테이블) 전제가 사라진다.

**커짐 근거**
- **U-L** — T-3 그 자체.
- **U-P** — `plist` 에 환경변수 키가 **0개**라 `EKS_REAPER_TTL` 우회가 막힌다.
- **U-V** — 왕복은 JWT 키 전환이 **2회** = **강제 로그아웃 2회**. D-013 은 *"전환 당일"* **1회**만 적었다.
