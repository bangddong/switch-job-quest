대조

교과서 3-tier 구성도와 무엇이 다른가

교과서여기왜
Route 53Cloudflare도메인이 Cloudflare 에 있다. ACM 검증도 수동 CNAME
CloudFront · WAF · Shield없음학습장에 붙일 이유가 없다. prod 는 Vercel 이 엣지를 담당
Public / Web / App / DB 4계층퍼블릭 서브넷 1종프라이빗 서브넷을 두면 NAT 가 필수가 된다
NAT Gateway × 20개시간당 과금. 노드가 퍼블릭 서브넷에서 IGW 로 직접 나간다
Multi-AZ · Auto Scaling단일 AZ · 노드 1~2대영속 EBS 가 2a 에 묶여 노드를 같은 AZ 로 고정 (실패 6종 ①)
RDS primary / secondaryin-cluster PostgresRDS 는 월 +$18. Neon 이 같은 일을 $0 에 한다
ElastiCache · EFS없음필요가 없다
차이는 실력이 아니라 목적이다

교과서 그림은 가용성을 사고, 이 구성은 destroy-after-use 로 학습 시간을 산다. NAT 하나($0.059/h ≈ 월 $43)만 붙여도 이 계정의 상시 비용이 38배가 된다.
